# 体验反馈工作台

体验反馈工作台是一个面向非产品岗位新人的轻量网页工具，帮助用户把零散、模糊的产品使用感受整理成结构化反馈。

## 问题背景

在一次真实但已匿名化的工作场景中，市场实习生需要体验某 AI 产品，并向产品同学提交反馈。在这次经历中，初版反馈以文档、截图和文字记录为主，在正式提交前被指出规范性、细节度与准确性不足，需要进一步补充；后续沟通中，产品同学也需要进一步追问。这次个人工作观察促成了本项目的产品假设。

本项目希望解决的问题是：没有成熟产品经验的市场、内容、运营人员，在需要反馈产品问题时，缺少一套简单、清晰的表达结构。

## 目标用户

第一版主要面向：

- 市场实习生
- 内容运营、用户运营、增长运营新人
- 需要向产品或研发人员反馈问题，但缺少产品表达经验的非产品岗位人员

这些用户通常能描述自己的使用感受，但不熟悉如何拆分“使用背景、用户目标、操作步骤、实际结果、预期结果和影响”。

## 第一版核心能力

第一版只保留一个小而完整的反馈整理闭环：

1. 在首页查看产品说明和历史反馈
2. 新建或编辑一条反馈
3. 按三步引导填写使用场景、问题事实、影响与期望
4. 检查缺失字段并获得补充建议
5. 预览结构化反馈
6. 复制整份结构化纯文本
7. 使用浏览器本地保存、查看、编辑和删除历史反馈

第一版只复制结构化纯文本，不提供 Markdown 复制；不做完整度数字分数；不使用文字长度判断内容准确性。

## 当前项目阶段

当前项目处于产品规划与文档整理阶段。仓库目前只沉淀产品说明和产品规格文档，尚未进入网页开发阶段。

## 真实性说明

本项目基于一次个人工作观察提出产品假设，尚未完成外部用户访谈、可用性测试或大范围用户验证。因此，文档中不能把该问题描述为已经被普遍验证的用户结论。

更准确的表达是：

> 基于个人工作观察，部分非产品岗位新人可能在提交产品反馈时缺少结构化表达方法，本项目尝试通过引导式表单和反馈预览帮助他们提高反馈的结构性和完整性。

本产品只能帮助用户提高反馈的结构性和完整性，不能保证反馈一定准确，也不能保证产品团队一定理解或采纳。

## 隐私与匿名提醒

本项目展示和使用时不得填写真实公司、产品、部门、同事、客户或内部资料名称。案例统一使用“某 AI 产品”“市场实习生”“产品同学”等匿名表达。

第一版计划使用浏览器本地保存。数据只保存在当前浏览器中，清除浏览器数据后可能丢失，也不会自动同步到其他设备。
